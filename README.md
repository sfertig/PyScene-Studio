# PyScene-Studio

[PyScene Python Package](https://github.com/sfertig/PyScene)

PyScene-Studio if for those who want to try PyScene but want a more visual game engine style work environment

## Keybinds to keep in mind (while in editor):

* f1 OR ctrl+s -> Manual save *(engine also autosaves often)*
* shift+esc -> Close the program as a whole *(used for testing and may be removed later)*
* ctrl+a (or btn) -> add object to a scene
* f5 (or btn) -> Run project *(builds before the run)*
* f6 (or btn) -> Build project *(if you want to build to look for errors)*
